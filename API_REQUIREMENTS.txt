狀態說明：

[待提供]：畫面目前使用前端假資料或 localStorage，需要後端 API。
[建議]：不是畫面上線的絕對必要項目，但建議由後端集中管理。

*  必填

======================================================================
二、共通規格
======================================================================

1. 日期時間
   - 日期使用 YYYY-MM-DD，例如：2026-09-22。
   - 日期時間使用 ISO 8601 並包含時區，例如：
     2026-08-07T07:50:00+08:00。
   - API 回傳原始日期時間，顯示格式由前端處理。

2. 一般成功回應
   {
     "success": true,
     "data": {}
   }

3. 分頁成功回應
   {
     "success": true,
     "data": [],
     "meta": {
       "page": 1,
       "pageSize": 20,
       "total": 100,
       "totalPages": 5
     }
   }

4. 錯誤回應
   {
     "success": false,
     "error": {
       "code": "VALIDATION_ERROR",
       "message": "欄位資料不正確",
       "fields": {
         "account": "帳號為必填"
       }
     }
   }

5. HTTP 狀態碼
   - 200：查詢或更新成功
   - 201：新增成功
   - 204：刪除或無內容操作成功
   - 400：請求格式錯誤
   - 401：尚未登入或登入已失效
   - 403：沒有權限
   - 404：資料不存在
   - 409：重複報名、重複推薦等狀態衝突
   - 422：欄位驗證錯誤
   - 500：伺服器錯誤

6. 身分驗證
   - 個人資料、學習紀錄、報名與外訓功能皆須登入。
   - 建議使用 Secure、HttpOnly、SameSite Cookie 維持登入狀態。
   - 前端不應保存密碼或存取權杖於 localStorage。

三、已有 API
======================================================================

3.1 學術演講列表 [已有]

方法／網址：
GET https://nlms.tzuchi.com.tw/speech/sp.json

用途：
首頁「學術演講」卡片列表。

查詢參數：
目前無。

目前回應格式：JSON Array（不是共通回應 envelope）

每筆欄位：
* id       string  演講 ID
* title    string  演講標題
* data     string  演講日期，格式 YYYY-MM-DD
                     注意：來源欄位名稱確實是 data，不是 date
* img      string  相對於 /speech/ 的縮圖路徑
* speaker  string  講師姓名，多位講師可用來源字串呈現

前端衍生欄位：
- thumbnailUrl = https://nlms.tzuchi.com.tw/speech/ + img
- targetUrl = https://nlms.tzuchi.com.tw/speech/watch.php?id={id}

範例：
[
  {
    "id": "1090",
    "title": "跨領域團隊照護會議─脆弱性骨折",
    "data": "2026-09-22",
    "img": "uploads/thumbnails/thumb_6ab21ba37aa45.jpg",
    "speaker": "謝明宏"
  }
]

注意事項：
- 正式站若不是與 nlms.tzuchi.com.tw 同網域，來源伺服器必須提供 CORS。
- 開發環境目前透過 webpack Proxy 存取此 API。

四、登入與會員
======================================================================

4.1 登入 [待提供／P0]

方法／建議路徑：
POST /api/v1/auth/login

Request JSON：
* account   string   帳號
* password  string   密碼
? remember  boolean  是否保持登入，預設 false

Response data：
* user.id          string
* user.account     string
* user.name        string
? user.campusId    string
? user.campusName  string
? user.departmentId string
? user.departmentName string
* user.roles       string[]，例如 ["learner"]
? expiresAt        string，登入到期時間


4.2 取得目前登入者 [待提供／P0]

方法／建議路徑：
GET /api/v1/auth/me

Response data：同 4.1 的 user。
未登入時回傳 401，不應以固定假使用者代替。


4.3 登出 [待提供／P0]

方法／建議路徑：
POST /api/v1/auth/logout

Request：無。
Response：200 或 204，並使伺服器端 Session／Cookie 失效。


4.4 忘記密碼 [待提供／P1]

方法／建議路徑：
POST /api/v1/auth/forgot-password

Request JSON：
* account  string  使用者帳號

Response data：
* message  string  不應透露帳號是否存在

? attributeId  string

9.2 外訓資料詳情 [待提供／P0]

方法／建議路徑：
GET /api/v1/external-trainings/{trainingId}

Response data：包含 9.1 欄位，另加：
* rocYear         integer  民國年度，例如 115
* applicability   string   自主外訓／醫師學會發表／進修學術報告／其他
* durationMinutes integer

  - content        integer  1～5

  - learningOutcome integer 1～5
  - expectation    integer  1～5
? reflection      string
* attachments     Array
  - id            string
  - fileName      string
  - contentType   string
  - size          integer  bytes
  - downloadUrl   string

9.3 建立外訓資料 [待提供／P0，需登入]

方法／建議路徑：
POST /api/v1/external-trainings

Content-Type：multipart/form-data

表單欄位：
* rocYear          integer
* applicability    string
* title            string
* organization     string
* trainingStartAt  string  ISO 8601
* trainingEndAt    string  ISO 8601，必須晚於 trainingStartAt
* durationMinutes  integer，須大於或等於 0
* attributeIds[]   string[]
* satisfaction     JSON string，內容同 9.2 satisfaction
? reflection       string
* applyForCredit   boolean
? files[]          File[]

Response：201，data 為完整的外訓資料詳情。


9.4 推薦外訓心得 [待提供／P1，需登入]

======================================================================
十、不需要 API 的資料
======================================================================

下列內容目前可繼續由前端設定管理：
1. 主選單與其他平台連結。
2. 學習服務入口圖示與固定網址。
3. 顏色、圖示、分頁筆數選項與 RWD 顯示方式。
4. 外訓尚未送出的本機草稿；目前可保存在 localStorage。
5. 純顯示文字，例如按鈕名稱、欄位標籤與空資料訊息。


======================================================================
十一、後端實作前尚需確認
======================================================================

1. API 實際網域、版本前綴及正式／測試環境網址。
2. 登入是否沿用既有 LMS Session 或需要 SSO。
3. 學術演講網站與學習網是否共用登入狀態。
4. 課程報名使用新 API，或仍導向既有 course_opration.php。
5. 課程狀態、學程狀態與外訓審核狀態的正式代碼表。
6. 外訓附件允許的副檔名、單檔大小、總大小及檔案數量。
7. 哪些角色可查看全院外訓資料及執行學分審核。
8. 公告、影片及通知是否需要多語欄位。
9. 列表最大 pageSize、排序規則與資料保留期限。
10. 所有跨網域 API 的 CORS、Cookie SameSite 與 CSRF 規則。


======================================================================
十二、建議開發優先順序
======================================================================

P0（畫面正式上線必要）
- 登入、目前使用者、登出
- 首頁公告、學習摘要、精選影片、一分鐘知識
- 消息／公告列表
- 課程選項、課程列表、課程詳情、報名
- 行事曆事件、學程列表、學程進度
- 外訓列表、詳情、建立

P1（主要互動完整化）
- 忘記密碼
- 通知已讀／全部已讀
- 取消報名
- 外訓推薦
- 學程學分審核

P2（管理彈性）
- 取消推薦
- 外訓表單選項 API
